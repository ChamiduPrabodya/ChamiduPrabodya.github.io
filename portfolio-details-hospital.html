Doctor Appointment and Hospital Operations App

This project is a hospital management mobile application built with React Native and Expo to support healthcare operations through a modern mobile experience.

The app includes user authentication, doctor browsing, appointment booking, payments, complaints, reports, and an admin dashboard for managing hospital workflows from a mobile device.

It is designed as a connected healthcare system that works with a backend API, making it suitable for hospital services, appointment coordination, and operational monitoring.

Key Features

  • Login, registration, and profile management
  • Doctor listing and doctor details
  • Appointment booking with date and time selection
  • Payment tracking and complaint management
  • Report generation and history
  • Admin dashboard for hospital operations

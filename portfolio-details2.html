AI-Powered Plant Health Monitoring

This project focuses on detecting plant diseases using an AI-assisted workflow to help identify crop issues earlier and support better agricultural decisions.

The solution is designed around simple monitoring and image-based analysis so that users can check plant conditions more easily and respond before damage spreads.

It reflects an interest in combining software, agriculture, and intelligent systems to build practical tools for real-world use.
